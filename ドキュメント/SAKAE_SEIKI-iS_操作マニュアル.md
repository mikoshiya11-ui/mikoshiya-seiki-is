# SAKAE SEIKI-iSの全体フロー

SAKAE SEIKI-iSは、**作業票を中心に使う**システムです。案件一覧から作業票を開き（または作成し）、そこから個別日程表・印刷帳票・受注に関する連絡書へ進みます。

```
案件一覧
  ↓
作業票
  ├─ 個別日程表
  ├─ 作業開始印刷セット
  │    ├─ 作業票表紙（A5横）
  │    ├─ 手配チェックシート（A4横）
  │    └─ カンバン（A4縦・上下2面）
  └─ 受注に関する連絡書
```

さらに詳しくは以下のようにつながっています。

```
① 案件一覧
    └─ 新規登録／検索
           ↓
② 作業票
    ├─ ③ 個別日程表
    │      └─ NC/NCM工程 → ⑥ NC日程表
    ├─ ④ 作業開始印刷セット
    │      ├─ ④-1 作業票表紙
    │      ├─ ④-2 手配チェックシート
    │      └─ ④-3 カンバン
    └─ ⑤ 受注に関する連絡書

⑦ 実績入力
    └─ 完了実績 → ⑧ 工程別残品表

⑨ 支給・納品一覧
    └─ 現状は独立
```

> ⚠ 注意：受注に関する連絡書は必要な正式書類ですが、**先に作らないと作業票へ進めない、という仕組みではありません**。実際の業務では、作業票（さらに個別日程表）を先に作り、そこで入力した客先名・型式・数量・納期などが受注に関する連絡書にも自動的に反映されます。連絡書はどちらで編集しても、もう片方に反映されます。

# 案件一覧

ファイル：`SAKAE SEIKI-iS.html`

## 役割

すべての案件を検索・一覧表示し、**作業票を開くための入口画面**です。新規案件の登録もここから行います。

## 操作説明

| 操作 | 内容 |
|---|---|
| カード本体をクリック | その案件の作業票へ移動します。既に作業票がある場合は「作業票を開く」、無い場合は「作業票を作成する」と表示されます |
| カードの「詳細」ボタン | 受注に関する連絡書の内容（客先・型式・受注日・納期・特記事項など）を確認するモーダルを開きます |
| 検索ボックス＋「検索」 | 社内No.・客先名・型式名でカードを絞り込みます |
| ＋新規作成 | 社内No.（品番）を入力するだけで新しい案件を登録し、**そのまま作業票へ移動します** |
| [一覧]ひな形から作成 | 登録済みの「ひな形（テンプレート）」から部品・工程を引き継いで新規作成します |
| すべて／進行中案件／完了案件(CSV出力) | 一覧の表示フィルタを切り替えます |
| [出力]データを書き出し（JSON） | カードと、紐づく作業票・個別日程表などのデータをまとめて1つのJSONファイルにダウンロードします（別PC・別ブラウザへの移行やバックアップ用） |
| [入力]データを読み込み（JSON） | 書き出したJSONファイルを選択して読み込み、今の画面のデータを丸ごと置き換えます |
| [書類]完了案件をCSV書き出し | 「完了（過去制作分）」の案件だけをまとめてCSVでダウンロードします |

> ⚠ 注意：JSONの読み込みは、今のデータを**すべて置き換えます**（一部だけ追加する機能ではありません）。読み込む前に、今のデータが必要であれば先に書き出しておいてください。

# 作業票

ファイル：`システムファイル/作業票_モック.html`

## 役割

部品・工程を管理するだけでなく、個別日程表・印刷帳票・受注に関する連絡書へ進む**案件の中心画面**です。

## 上部の関連機能ボタン

| ボタン | 操作内容 |
|---|---|
| [印刷] 作業開始印刷セット | 作業票表紙・手配チェックシート・カンバンの選択画面を開きます |
| [日程] 個別日程表を開く | 同じ品番のガントチャート（個別日程表）を開きます |
| [書類] 受注に関する連絡書 | 同じ品番の受注に関する連絡書を開きます |
| [印刷] 現行の作業票印刷 | 部品ごとの作業票印刷画面を開きます（従来からある印刷機能） |

## 基本情報

品番・社内No・発行日・受注日・作成日・作成者・発送日・納期・客先名・型式名・**品名・数量**・組付有無を入力できます。ここで入力した客先名・型式・品名・数量・納期などは、受注に関する連絡書にも自動的に反映されます。

## その他の操作

| 操作 | 内容 |
|---|---|
| ＋部品を追加 | 部品の行を1つ追加します |
| [表示] 注記を縦書き表示 | 注記欄の表示を縦書き・横書きで切り替えます |
| 工程を編集 | 各部品の工程（DE/SU/PN/NC/…）と日付を設定します |
| [確定] 工程と納期を確定する | チェックすると、以後は工程の追加・削除・日付・午前午後の変更ができなくなります（個別日程表とも連動してロックされます）。誤操作防止用です |

# 個別日程表

ファイル：`システムファイル/個別日程表_モック.html`

## 役割

品番ごとの工程日程を、ガントチャート（横棒グラフ）で表示・編集する画面です。作業票と同じデータを共有しています。

## 操作説明

| 操作 | 内容 |
|---|---|
| バーの中央をドラッグ | その工程の日付（開始位置）を移動します。作業票側にもその場で反映されます |
| バーの両端をつまんで左右に伸縮 | 作業期間（日数）を変更します |
| 進捗チェック欄 | 担当者名×日付でチェックを付けられる確認用の表です。担当者名は画面上で追加・改名・削除できます |
| ＋メモを追加 | 自由記述の付箋（メモ）を配置できます。縦書き表示への切り替えも可能です |
| ズーム（－／100%／＋） | 表示の拡大・縮小をします |

NC・NCM工程は、ダブルクリックすると④NC日程表（機械別の日程表）へ移動できます。

\newpage

# 作業開始印刷セット

ファイル：`システムファイル/作業開始印刷セット_モック.html`

## 役割

作業開始時に使用する3帳票（作業票表紙・手配チェックシート・カンバン）をまとめた入口画面です。対象品番・社内No・客先・品名が表示されます。

> ⚠ 注意：3帳票は用紙サイズ（A5横／A4横／A4縦）が異なるため、**1回の印刷操作でまとめて出すことはできません**。1枚ずつ、この画面から開いて印刷してください。

## 操作手順

1. 作業票で「[印刷] 作業開始印刷セット」を押す
2. 「① 作業票表紙」の「表示・印刷」を押して開き、印刷する
3. 「② 手配チェックシート」の「表示・印刷」を押して開き、必要事項を入力・保存してから印刷する
4. 「③ カンバン」の「表示・印刷」を押して開き、印刷する
5. 「← 作業票へ戻る」で作業票に戻る

\newpage

# 作業票表紙

ファイル：`システムファイル/作業票表紙_モック.html`（A5横）

## 役割

作業票から自動生成される、印刷専用の表紙です。基本情報を再入力する必要はありません。

## 表示内容

社内No・発行日・客先・品番・品名・型番・数量・受注日・納期・工程・着手・完成に加えて、実績入力に記録がある場合は実働Hが自動表示されます。

> ⚠ 注意：機械名・作業No・外注／担当者・見積Hは、現時点でシステムに入力欄が無いため空欄のまま印刷されます。必要であれば手書きで記入してください。実働Hも、実績入力に記録が無い場合は空欄のままです（見積の工数が表示されることはありません）。

## 印刷手順

1. 作業開始印刷セットから「① 作業票表紙」を開く
2. 内容を確認する（修正が必要なときは作業票へ戻って直す）
3. 右上の「[印刷] 印刷」を押し、A5横で印刷する

\newpage

# 手配チェックシート

ファイル：`システムファイル/手配チェックシート_モック.html`（A4横）

## 役割

設計図面・材料手配・日程表作成・出図など、手配に関わる12項目の進捗を記録する画面です。

## 操作説明

- 社内No・品番・型番・品名は作業票から自動的に表示されます
- 入力日・区分（新作／修改／予備品）を設定すると、各項目の「期限」が自動計算されます
- 各項目の完了日・確認者を入力すると、自動的に保存されます
- 別のパソコンで開いていても、内容が共有されます

> ⚠ 注意：期限の自動計算は、**土日だけを除外**した簡易な計算です。祝日や会社の休業日は考慮されませんので、その分は目安として手動で調整してください。

## 印刷手順

1. 作業開始印刷セットから「② 手配チェックシート」を開く
2. 入力日・区分・各項目の完了日／確認者を入力する（自動保存されます）
3. 印刷前に入力内容を確認する
4. 右上の「[印刷] 印刷」を押し、A4横で印刷する

\newpage

# カンバン

ファイル：`システムファイル/カンバン_モック.html`（A4縦）

## 役割

現物の識別に使う「カンバン」を印刷する、**入力画面ではなく印刷専用**のビューです。

## 表示内容

型番と品名を大きく表示し、下部に社内No・数量・客先・納期を補助情報として小さく表示します。1枚のA4用紙に同じ内容を上下2面印刷し、中央の切り取り線で切り分けて使用します。

## 印刷手順

1. 作業開始印刷セットから「③ カンバン」を開く
2. 表示内容を確認する
3. 右上の「[印刷] 印刷」を押し、A4縦で印刷する
4. 印刷後、中央の切り取り線で2枚に切り分ける

\newpage

# 受注に関する連絡書

ファイル：`SAKAE SEIKI-iS.html`（作業票から開くと連絡書の編集画面が表示されます）

## 役割

正式な受注書類です。作業票から開くと、共通する項目（客先・品名・数量・受注日・納期・型式・社内No）は**すでに入力済みの状態**で表示されます。

## 操作説明

| 操作 | 内容 |
|---|---|
| 作業票の「[書類] 受注に関する連絡書」ボタン | 対象品番の連絡書を開きます |
| 共通項目を変更する | 客先・品名・数量・受注日・納期などを連絡書側で変更すると、作業票にも反映されます |
| 連絡書固有項目 | 品種・見積・登録事項・特記事項など、連絡書だけにある項目を追加で入力します |
| 「← 作業票に戻る」 | 入力内容を保存してから、同じ品番の作業票へ戻ります |

\newpage

# NC日程表

ファイル：`システムファイル/NC日程表_モック.html`

## 役割

NC・NCM工程を「機械」ごとに横串で管理する専用のガントチャート画面です。機械の空き状況を見ながらジョブを割り付けます。

## 操作説明

| 操作 | 内容 |
|---|---|
| 空いている枠を右クリック→「バーの設置」 | 新しいバーを配置します |
| 既存バーを右クリック→「編集」 | バーの内容を編集します |
| 既存バーを右クリック→「工程の日程表」 | 元の工程別日程表ページを開きます |
| [印刷]印刷する（A3） | A3サイズでの印刷に最適化して印刷します |
| [確定]計画を確定する | バー配置を確定してロックします |

# 実績入力

ファイル：`システムファイル/実績入力_モック.html`

## 役割

どの工程が・誰によって・いつ完了したか、実績を記録する画面です。バーコード読み取り、または品番一覧からの手動選択で対象を選べます。

## 操作説明

| 操作 | 内容 |
|---|---|
| （バーコード読み取り） | バーコードリーダーで品番・工程を読み取ると自動的に対象がセットされます |
| 品番から選ぶ（手動） | 品番の一覧から直接対象の工程を選ぶモードに切り替えます |
| 登録する（Enterキーでも可） | セットされている工程の完了実績を記録します |
| 一覧の× | 誤って登録してしまった実績を1件削除します |

> ⚠ 注意：ここで登録した実績時間（段取・有人・無人・夜間）は、**作業票表紙の実働Hにも使われます**。作業実績が1件も無い場合、表紙の実働Hは空欄のままです。誤登録を削除すると、表紙側の実働Hの数値も変わることがあります。また、既に開いている作業票表紙の画面には、別のパソコンで登録した実績がその場では反映されません。次にその画面を開き直したときに反映されます。

ファイル：`システムファイル/残品表_モック.html`

## 役割

作業票にある全部品・全工程と、実績入力の完了記録を突き合わせて、**まだ終わっていない部品**を工程別に一覧表示します。

## 操作説明

| 操作 | 内容 |
|---|---|
| チェック欄 | 目視確認用の目印です。**実際の工程完了の記録は必ず実績入力側で行ってください** |
| まとめて削除 | 該当しなくなった残品行をまとめて削除します |

# 保存・共有・印刷に関する注意

## 保存について

- どの画面も「保存ボタン」を押さなくても、入力すると自動的にブラウザに保存されます（手配チェックシートのみ、右上の「保存」ボタンでも保存できます）
- ログインした状態では、保存内容は自動的にクラウド（Supabase）にも送られ、他の担当者の画面にも数秒以内に反映されます

## 画面を移動するときの注意

- 入力した直後に別の画面へ移動しても、**送信が完了してから移動する**ようにできています（作業票→個別日程表、作業票→作業開始印刷セット、作業票⇔受注に関する連絡書、案件一覧→作業票など、主要な移動先で対応済みです）
- 印刷用の画面（作業票表紙・手配チェックシート・カンバン）は、URLに品番を含んだ形で開かれます。作業票・受注に関する連絡書・印刷帳票はすべて同じ品番のデータを見ているため、同じ内容を別々の画面で入力し直す必要はありません

## 元に戻す

多くの画面で、画面下に一時的に出る「元に戻す」通知から、直前の操作を取り消せます。
